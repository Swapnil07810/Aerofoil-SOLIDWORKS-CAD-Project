# Aerofoil-SOLIDWORKS-CAD-Project
 Mechanical CAD project, an aerofoil blade I modelled in SOLIDWORKS 2024. I drew curves on several planes, joined them with a loft to get the twisted shape, then added a root block, a fillet and a few cuts.  **Application:** Blades like this are used in gas turbines, jet engines, wind turbines and fans.
